How to Register this App in Entra ID (Free)

  1. Log into the Microsoft Entra Admin Center (or Azure Portal).
  2. Navigate to Applications > App registrations and click New registration.
  3. Enter a name (e.g., Spurk Employee Hub).
  4. Set Account Type to: Accounts in this organizational directory only (Single tenant).
  5. Under Redirect URI, select Single-page application (SPA) and type your GitHub Pages URL (e.g., https://yourusername.github.io/spurk-hub/) or http://localhost:3000 for local test.
  6. Click Register, copy the generated Application (client) ID, and paste it into the field above.
  7. Go to API permissions, click Add a permission > Microsoft Graph > Delegated permissions, and select:
    • User.Read
    • Mail.Send
    • Calendars.Read
    • Files.ReadWrite

GitHub Pages Deployment Guide

  1. Create a new GitHub repository named spurk-hub.
  2. Upload this index.html file to the root of the repository.
  3. Go to Repo Settings > Pages. Under Branch, select main / root and click Save.
  4. Add the published GitHub Pages URL to your Azure SPA Redirect URIs.
